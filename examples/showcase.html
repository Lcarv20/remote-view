Remote-View Showcase

Agents output only the inner HTML fragment; drop-html wraps it in the preloaded shell, pushes it over SSH to your Raspberry Pi, and returns a clickable LAN URL.

Phone & Browser-Tool Ready: Because drops are served over plain HTTP on your LAN, both your mobile browser and agent browser tools can inspect the exact same rendered output.
RAM Footprint ~2 MB

Served 24/7 by lighttpd inside a systemd unit.
Token Burn -80%

No HTML head, CDN imports, or CSS boilerplate per drop.
Math Check KaTeX

Latency bound: \(T_{\text{total}} = T_{\text{ssh}} + T_{\text{http}}\)
