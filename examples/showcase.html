Remote-View Showcase

A calm, paper-inspired reading shell served directly from your Raspberry Pi. Plain prose, tables, diagrams, and code stay clean and legible without wrapping every paragraph in cards.

Self-hosted assets: CSS, JS, fonts (Fraunces, IBM Plex Sans, JetBrains Mono), and 54 Tabler icons live locally under /_assets/.

Architecture & Delivery

drop-html wraps inner fragments into a single page, while drop-dir pushes full build directories (dist/, build/) over SSH. 

flowchart LR
  A["Coding Agent"] -->|fragment| H["drop-html"]
  A -->|dist/| D["drop-dir"]
  H -->|SSH| PI["bluyeti-pi.local\nlighttpd :80"]
  D -->|tar over SSH| PI
  PI -->|LAN HTTP| U["Phone / Desktop / Browser"]
  PI -.->|off-LAN| CF["cloudflared Tunnel"]
    
# Publish an HTML fragment
drop-html --title "Architecture Notes" <<'REMOTE_VIEW_EOF'
<h1>Write-Through Cache</h1>
<p>No HTML head or CSS setup needed.</p>
REMOTE_VIEW_EOF

# Publish a build directory
vite build --base=./
drop-dir --id my-app dist/
